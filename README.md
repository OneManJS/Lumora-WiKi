# NextMediaHub 使用说明

（以下内容均有Ai生成）

NextMediaHub 是一个兼容Emby协议的私人媒体服务器：把磁盘上的电影和剧集整理成漂亮的海报墙，家人朋友用网页或支持Emby协议的客户端就能在线观看。本 wiki 全部以**实际界面截图 + 操作步骤**编写，跟着做即可。

## 界面速览

**观影端**（所有人使用）：登录后就是海报墙首页，浏览、搜索、播放都在这里。

![观影端首页](images/05-home.png)

**管理控制台**（管理员使用）：左侧导航分四组——工作台（每天看）、内容（经常改）、运行（出问题才看）、系统（配好就不动）。

![管理控制台运行概览](images/02-overview.png)

## 三分钟上手路径

1. [安装并启动服务](01-安装部署.md)，浏览器打开 `http://服务器地址:18096/`
2. [创建管理员账号](02-首次使用.md#2-创建管理员账号)
3. [新建媒体库](03-媒体库管理.md#1-新建媒体库)指向你的电影/剧集文件夹，点「扫描」
4. 等任务跑完，回首页开始观看 🎬

## 常见操作去哪点

| 想做什么 | 去哪里 |
| --- | --- |
| 加新的电影文件夹 | 管理控制台 → 内容 → 媒体库 → 新建媒体库 |
| 海报/简介不对 | 管理控制台 → 内容 → 媒体 → 打开影片 → 重新识别 |
| 给家人开账号 | 管理控制台 → 系统 → 用户与权限 → 新建用户 |
| 从老 Emby 搬家（用户+观看记录+收藏） | 管理控制台 → 系统 → Emby 数据导入 |
| 换自己的密码 | 右上角头像 → 账户与安全 |
| 让某部剧能跳片头 | 管理控制台 → 内容 → 片头片尾 |
| 给媒体库换封面 | 管理控制台 → 内容 → 封面工作室 |
| 看谁在看/看了什么 | 管理控制台 → 运行 → 播放活动 |
